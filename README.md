# Experiments
This repository contains experiments for building a multimodal model for skin lesion classification across 11 diagnostic categories. This repository makes use of the MILK10k dataset. The model architecture leverages 2 image modalities, and 2 metadata modalities (a close-up clinical image, a dermoscopic image, and their corresponding metadata).

# Setup
It is suitable for conducting the experiments on a kaggle environment, as this was the environment the experiments were conducted on. It requires enabling an accelerator for speeding up image processing, and adding the MILK10k dataset, which is available at [MILK10k Kaggle Dataset](https://www.kaggle.com/datasets/hamzabinbutt/isic-challenge-datasets).
